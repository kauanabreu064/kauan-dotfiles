# Kauan Dotfiles

Configuração do meu Arch Linux com Hyprland + Caelestia.

## Incluído

- Hyprland / Caelestia
- Kitty
- Fish
- Rofi Control Center
- Fastfetch
- Yazi
- Firefox customizado
- Spotify + Spicetify
- Perfis Normal, Programação, Gaming, Faculdade e Focus
- Atalhos personalizados

## Instalação

Recomendado em uma instalação funcional do Arch Linux.

```bash
sudo pacman -S git

git clone https://github.com/SEU_USUARIO/kauan-dotfiles.git ~/kauan-dotfiles

cd ~/kauan-dotfiles

./install.sh
